# Интерфейс отображения сигналов систем сигнализации

## Описание

Современный веб-интерфейс для отображения и управления сигналами систем сигнализации, созданный на основе требований из предоставленного изображения.

## Функциональность

### Основные возможности:
- **Фильтрация сигналов** по источникам (КПОС, МТН, МУН, СКАМ, ТС I/O, FБРДУ, РВ, ПУР/СМЗУ)
- **Поиск** по объектам, сообщениям и источникам
- **Группировка сигналов** в отдельные секции (ЖДИ, СКАМ)
- **Закрепление групп** для быстрого доступа
- **Сворачивание/разворачивание** групп данных
- **Квитирование сигналов** для подтверждения обработки
- **Удаление записей** с подтверждением
- **Просмотр детальной информации** о сигналах

### Цветовая индикация:
- 🔴 **Красный** - критические сигналы (превышение ДДТН)
- 🟡 **Желтый** - предупреждения (нарушение графика напряжения)
- 🔵 **Синий** - информационные сообщения
- 🟢 **Зеленый** - квитированные сигналы

## Использование

1. Откройте файл `signals.html` в браузере
2. Используйте кнопки фильтров для отображения сигналов определенных источников
3. Введите текст в поле поиска для поиска по содержимому
4. Нажмите на заголовки групп (ЖДИ, СКАМ) для сворачивания/разворачивания
5. Нажмите на иконку 📌 для закрепления групп
6. Используйте кнопки "Просмотреть", "Квитировать" и "×" для управления сигналами

## Технические особенности

### Адаптивный дизайн
- Интерфейс адаптируется под различные размеры экранов
- На мобильных устройствах таблицы оптимизированы для удобного просмотра

### Производительность
- Виртуализация данных для больших объемов сигналов
- Ленивая загрузка групп

### Безопасность
- Подтверждение удаления записей
- Валидация пользовательского ввода
- Защита от XSS атак

## Настройка

### Добавление новых источников сигналов:
1. Обновите массив `signalsData` в `js/signals.js`
2. Добавьте новую кнопку фильтра в HTML
3. Обновите логику фильтрации в JavaScript

### Изменение цветовой схемы:
1. Отредактируйте CSS классы в `css/signals.css`
2. Обновите логику определения типов сообщений в JavaScript

### Интеграция с сервером:
1. Замените статические данные на AJAX запросы
2. Добавьте обработку ошибок сети
3. Реализуйте автоматическое обновление данных
